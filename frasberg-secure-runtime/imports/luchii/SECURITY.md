# Security Policy  
Frasberg Platform • Frasberg, Inc. • Luchii • LINQ • Frasberg Technologies

Frasberg, Inc. maintains strict security, privacy, and vulnerability‑management standards across all Frasberg Platform components, including Luchii, Frasberg, LINQ agents, SDKs, infrastructure modules, and public repositories.  
This document outlines supported versions and the official process for reporting security issues.

---

## Supported Versions

Only actively maintained versions receive security patches.  
Older versions may continue functioning but are **not** guaranteed safe.

| Version | Supported | Notes |
|--------|-----------|-------|
| **5.1.x** | ✅ Yes | Current stable release; receives full security updates. |
| **5.0.x** | ❌ No | Deprecated; upgrade recommended. |
| **4.0.x** | ✅ Yes | Maintained for long‑term stability users. |
| **< 4.0** | ❌ No | End‑of‑life; no updates provided. |

---

## Reporting a Vulnerability

Frasberg, Inc. follows a responsible disclosure process to protect users, developers, and infrastructure.

### **1. Contact**
Report vulnerabilities privately to:

**security@frasberg.com**

Include:

- Detailed description of the vulnerability  
- Steps to reproduce  
- Impact assessment (if known)  
- Logs, screenshots, or proof‑of‑concept if available  
- A preferred method of contact for follow‑up  

### **2. Response Timeline**
You can expect:

- **Acknowledgment within 48 hours**  
- **Initial triage within 5–7 days**  
- **Full remediation timeline after assessment**  

Critical issues may trigger accelerated patch releases.

### **3. Disclosure Expectations**
- Do **not** publicly disclose the vulnerability until a fix is confirmed.  
- You may request public credit after resolution.  
- Frasberg, Inc. may coordinate CVE publication when applicable.

### **4. Scope**
This policy applies to:

- Frasberg Platform  
- Luchii  
- Frasberg  
- All Frasberg Technologies public repositories  
- Official SDKs, agents, and integrations  
- Infrastructure modules and deployment templates

---

## Security Commitment

Frasberg, Inc. and Frasberg Technologies is committed to maintaining a secure, stable, and transparent ecosystem.  
We appreciate all responsible disclosures that help strengthen the Frasberg Platform.
